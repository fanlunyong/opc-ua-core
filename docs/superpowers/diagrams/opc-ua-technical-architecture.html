Technical Architecture · 分层组件与依赖关系 · 2026-06-18

封装层 + 核心运行时

  • MiloClientWrapper: 状态机 + 指数退避
  • ConnectionManager: 连接池 + 负载均衡
  • SubscriptionManager: 批次聚合订阅
  • ReadWriteHandler: 定时轮询 + 同步写
  • DataDispatchEngine: 分桶异步分发
  • QualityEvaluator + DataMapper: 数据增强

API + 配置 + 基础设施

  • OpcUaService: 统一对外 Facade
  • OpcUaDataListener: 函数式回调接口
  • AutoConfiguration: SPI 自动装配
  • @ConfigurationProperties: 类型安全配置
  • Spring Boot 3.2 + Java 17 + Maven
  • Actuator HealthIndicator 健康检查

转发层（规划中）

  • HTTP Forwarder: Webhook 回调
  • Kafka Forwarder: 消息队列投递
  • MQTT Forwarder: IoT 协议推送
  • TSDB Forwarder: 时序数据库写入
  • Alert Router: 条件触发告警
  • REST Config API: 运行时配置管理
