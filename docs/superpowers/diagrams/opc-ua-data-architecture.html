OPC UA 核心采集层 — 数据架构图

Data Architecture · 数据流、数据模型与状态转换 · 2026-06-18

配置数据流

  • application.yml → OpcUaProperties 绑定
  • DeviceConfig: 设备、安全、订阅、轮询
  • DeviceHandle: 运行时连接池句柄
  • REST API 热更新（规划中）
  • 类型安全 + @ConfigurationProperties
  • @JsonIgnore 敏感字段保护

采集数据流

  • 订阅: NotificationListener 批次聚合
  • 轮询: opcua-poll-* 定时线程池
  • QualityEvaluator: StatusCode→Quality
  • DataMapper: displayName/dataType 回退
  • DataDispatchEngine: 分桶 + 哈希路由
  • CopyOnWriteArrayList 多播监听器

数据模型

  • OpcUaDeviceData: 顶层数据容器
  • OpcUaDataPoint: 单点数据值对象
  • DeviceState: 设备连接状态快照
  • ConnectionState: CONNECTED/RECONNECTING/DISCONNECTED
  • Quality: Good/Bad/Uncertain
  • 转发数据流: 4 通道输出（规划中）
